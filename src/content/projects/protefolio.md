### Visão Geral do Projeto
Desenvolvimento de uma presença online técnica e minimalista desenhada para apresentar competências de engenharia informática, infraestrutura e desenvolvimento. O projeto prioriza velocidade de carregamento, simplicidade arquitetural e independência de frameworks com runtime pesado no cliente.

### Decisões Técnicas e Arquitetura

- **Astro (SSG):** Geração de páginas 100% estáticas (*Static Site Generation*) com arquitetura de ilhas, garantindo carregamento instantâneo e pontuações máximas em métricas de performance (Lighthouse 100/100).
- **Tailwind CSS (v4):** Estilização utilitária moderna com esquema de cores escuro (*dark mode* nativo), tipografia técnica limpa e total responsividade para dispositivos móveis e desktop.
- **TypeScript:** Tipagem estática em todos os componentes e coleções de dados, assegurando robustez no código e prevenção de erros em tempo de compilação.
- **Automação CI/CD:** Pipeline de integração contínua configurado via GitHub Actions / Cloudflare Pages. Qualquer alteração ou novo projeto submetido na branch principal despoleta a validação, compilação e deploy em produção de forma autónoma.
